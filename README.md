# Enhanced Chat Notifications

Customizable screen and text notifications based on chat messages.

## Features

- **Custom notifications**: Configure up to 25 unique notifications based on game chat messages. Below an example with a purple screen + Antifire text based on the chat message stating that the antifire is about to expire.

- **Text Overlay**: Optionally display a text box (e.g. "Antifire") besides the screen notification. The text is drawn on top of the minimap, inventory and other interfaces, so it stays readable wherever you place it.

- **Multiple lines**: Use `<enter>` in the text to start a new line (e.g. `TEST<enter>DROP`), which keeps the text compact enough to fit in a corner of the screen.

- **Text modes**: Solid for X seconds, flash for X seconds, or solid until cancelled. Solid until cancelled reacts to interaction exactly like RuneLite's own screen flash: the text stays on screen for at least two seconds and then disappears on the first mouse movement, click or key press in the client.

![Custom notification example](https://i.imgur.com/zKpygjP.png)

## Use case examples, fully customizable
- Goading potion expiring → red flashing screen
- Receiving a valuable drop excluding runite ores → Gold solid screen
- Prayer regeneration potion has won off → Blue screen + text 'Prayer regen'
- Any game chat trigger → your own custom style
